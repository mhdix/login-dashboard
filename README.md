# 🧪 Simple User Login Demo (Next.js + TypeScript + SCSS)

این پروژه یک نمونه‌ی نمایشی ساده برای **فرآیند لاگین کاربر** است.

## ✨ توضیحات

- در این پروژه، کاربر به‌صورت **تصادفی از یک API شبیه‌سازی‌شده** دریافت می‌شود.
- با کلیک روی دکمه‌ی **ورود (Login)**، اطلاعات کاربر در `localStorage` ذخیره می‌شود.
- پس از ورود موفق، کاربر به صفحه‌ی **Dashboard** منتقل می‌شود.
- در صورت کلیک روی **خروج از حساب (Logout)**، اطلاعات حذف شده و کاربر به صفحه‌ی ورود (Auth) بازگردانده می‌شود.
- تنها کاربرانی که اطلاعاتشان در `localStorage` ذخیره شده‌اند، می‌توانند صفحات محافظت‌شده مانند داشبورد را ببینند.

## 🛠 تکنولوژی‌های استفاده‌شده

- ⚡ **Next.js** (ساختار App Router)
- 💅 **SCSS Modules** (استایل‌دهی مدرن و ساختاریافته)
- 💡 **TypeScript** (برای افزایش امنیت تایپ و توسعه‌پذیری)
- 📦 مدیریت ساده‌ی وضعیت با `localStorage`
- 🚫 محافظت از صفحات با شرط دسترسی بر اساس توکن
